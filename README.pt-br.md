# Noctis Theme para Omarchy

*[Read in English](README.md)*

Um tema elegante e corporativo para o [Omarchy](https://omarchy.org), extraído da identidade visual e paleta oficial de [Noctis Mkt](https://noctismkt.com.br/).

Focado em usabilidade e sobriedade, o tema oferece um fundo noturno limpo, com textos em off-white para reduzir a fadiga visual, e uma cor de destaque em tons de champanhe/dourado para garantir uma hierarquia visual elegante.

![https://raw.githubusercontent.com/maugustoldo/omarchy-noctis-theme/refs/heads/master/backgrounds/gradient-noctis.png](https://raw.githubusercontent.com/maugustoldo/omarchy-noctis-theme/refs/heads/master/backgrounds/gradient-noctis.png)

## Instalação

No seu Omarchy, basta rodar o comando oficial de instalação de temas:

```bash
omarchy theme install https://github.com/maugustoldo/omarchy-noctis-theme.git
```

## O que está incluso?

- **Motor Semântico Omarchy 4:** O tema é 100% aderente ao novo motor de temas do Omarchy, gerando as configurações do seu terminal, editor de texto e shell dinamicamente.
- **GTK & Ícones Colloid:** O tema usa nativamente o [Colloid Icon Theme](https://github.com/vinceliuice/Colloid-icon-theme) e o [Colloid GTK Theme](https://github.com/vinceliuice/Colloid-gtk-theme) (na variação *Yellow Nord Dark Rimless*), assegurando uma interface de usuário impecável para as janelas do sistema.
- **Sublime Text:** Um tema de sintaxe para Sublime Text (`Noctis.sublime-color-scheme`) está incluso na pasta `/sublime`, pronto para ser ativado.
- **Background Minimalista:** O tema acompanha um wallpaper exclusivo (`noctis-spotlight.png`) com um degradê radial escuro sutil.
