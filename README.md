# Noctis Theme

Um tema elegante e corporativo para o Omarchy, extraído da paleta oficial de [Noctis Mkt](https://noctismkt.com.br/).

## Características
- Minimalista, elegante e focado.
- Acentos em tons champanhe/dourado (`#ead99e`).
- Fundo noturno e limpo.
- Cores de sintaxe desenhadas para não gritar na tela, preservando a paz visual.
