# Noctis Theme for Omarchy

*[Leia em Português (PT-BR)](README.pt-br.md)*

An elegant and corporate theme for [Omarchy](https://omarchy.org), extracted from the official visual identity and palette of [Noctis Mkt](https://noctismkt.com.br/).

Focused on usability and sobriety, the theme offers a clean nocturnal background, with off-white texts to reduce eye strain, and an accent color in champagne/gold tones to ensure an elegant visual hierarchy.

![https://raw.githubusercontent.com/maugustoldo/omarchy-noctis-theme/refs/heads/master/backgrounds/gradient-noctis.png](https://raw.githubusercontent.com/maugustoldo/omarchy-noctis-theme/refs/heads/master/backgrounds/gradient-noctis.png)

## Installation

In your Omarchy environment, just run the official theme installation command:

```bash
omarchy theme install https://github.com/maugustoldo/omarchy-noctis-theme.git
```

## What's included?

- **Omarchy 4 Semantic Engine:** The theme is 100% compliant with the new Omarchy theme engine, dynamically generating configurations for your terminal, text editor, and shell.
- **Colloid GTK & Icons:** The theme natively uses the [Colloid Icon Theme](https://github.com/vinceliuice/Colloid-icon-theme) and the [Colloid GTK Theme](https://github.com/vinceliuice/Colloid-gtk-theme) (in the *Yellow Nord Dark Rimless* variation), ensuring a flawless user interface for system windows.
- **Sublime Text:** A syntax theme for Sublime Text (`Noctis.sublime-color-scheme`) is included in the `/sublime` folder, ready to be activated.
- **Minimalist Background:** The theme includes an exclusive wallpaper (`noctis-spotlight.png`) with a subtle dark radial gradient.
